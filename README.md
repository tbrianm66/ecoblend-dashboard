# EcoBlend Dashboard

A hub-and-spoke analytics dashboard for the EcoRace Venture Studio, visualising the dual Venture Readiness Level (VRL) and Technology Readiness Level (TRL) framework across the portfolio of spin-off ventures.

🤖 *Built and maintained with the help of Manus AI.*

## 🛠️ Tech Stack
- **Frontend:** TypeScript, Vite, React
- **Backend/Database:** Node.js, Drizzle ORM
- **Package Manager:** pnpm
- **Environment:** Developed via Replit

## 📂 Repository Structure
- `/client`: Frontend user interface and dashboard components.
- `/server`: Backend API routes and logic.
- `/drizzle`: Database schemas and migrations.
- `/shared`: Shared TypeScript types and utilities between client and server.
- `/scripts`: Automation and utility scripts.
